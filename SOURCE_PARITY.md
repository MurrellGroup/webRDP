Full exploratory mode constructs exactly one `a < b < c` record per unordered
concrete sequence triplet. RDP, GENECONV and the combined MAXCHI/CHIMAERA
production kernels each receive that record once and resolve their internal
tracks and polarities in context. BootScan consumes the same record set as one
shared-pair batch, matching the source optimization instead of recomputing
three pairs per triplet. Packed extraction advances sixteen columns per word
and materializes only the current triplet's informative coordinates. No
detector uses an alignment consensus or unselected sequences as a third-member
proxy. Kernel-call provenance and the C(5,3) regression guard these properties.

## Compatibility policy

- Source mode is deterministic for a saved random seed and records the mode in
  every project.
- Historical quirks are retained when they affect output and are called out in
  code comments/tests rather than silently “fixed.”
- Source-derived and fallback calculations are labeled separately in the UI,
  project JSON, and CSV.
- A method is not called complete until its independent locator, statistic,
  calibration, circular/missing-data behavior, and desktop golden fixtures all
  pass.
